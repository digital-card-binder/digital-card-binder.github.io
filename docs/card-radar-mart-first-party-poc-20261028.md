# 카드 레이더 — 롯데마트·토이저러스 / 이마트 원본 조회 POC (2026-10-28)

## 결론

**마트 점포별 자동 실재고의 운영 연결은 여전히 미완료.** 도감앱·PokeConv DB를 사용하지 않고 판매처 원본 서비스만 검토한다.

- 롯데마트 모바일 도와센터에는 공식 `상품 확인` 화면이 존재한다: https://company.lottemart.com/mobiledowa/
- 공식 롯데마트GO 앱에도 점포 재고 조회 기능이 있다. 하지만 상품 제공과 독립 서버 자동 재배포 허용은 별개다.
- 이마트 공식 앱은 점포별 수량 조회 기능을 안내하지만 공개 웹 페이지에는 점포별 재고 API 응답이 확인되지 않았다.
- 롯데마트 제타 온라인 쇼핑에서 `available`은 오프라인 매장 재고의 수량이 아니다. 재고 수량 0/1로 전환하거나 점포 전체에 재사용 금지.

## 적용된 독립 코드

- `radar-service/lib/mart-first-party.mjs`: 지역·롯데마트/토이저러스 점포코드·검색어·GTIN(상품 바코드)·판매단위(낱팩/박스/덱/세트) 필수 검증. 공식 모바일 도와센터의 매장 옵션과 상품 검색 HTML을 엄격하게 파싱하고 수량 숫자 및 명시적 품절만 인정. 상품 바코드가 없거나 패키지 불일치·웹 오류일 때 수량을 **미확인** 처리. 7초 제한, 성공 결과만 30초 캐시.
- `radar-service/api/v1/mart-original.js`: **기본 비활성화(503)**. 롯데마트·토이저러스는 `RADAR_MART_DATA_USE_APPROVED=1`과 `RADAR_LOTTEMART_DIRECT_PUBLISH=1` 둘 다 운영자 승인한 경우에만 공개. 이마트는 실재고 경로가 확인되지 않아 무조건 미연동 응답.
- `tests/radar-mart-first-party.test.mjs`: 알려진 상품·매장코드, 잘못된 바코드, 낱팩과 박스 혼동, 명시적 0개, 수량 미확인, API 기본 차단을 검증.
- 기존 레이더의 편의점/공식 자판기/회원 보유 기록은 변경하지 않음.

## 다음 운영 검증 조건

1. 롯데마트의 공식 서버가 정상적으로 응답하는 적합한 **허용된 네트워크·배포 환경**과 데이터 사용 가능 범위를 먼저 확보한다. 접근 제한 우회 금지.
2. 원본에서 실제 카드 상품의 GTIN, 상품명·규격, 점포코드와 수량을 같은 시점에 취득한다. 1개의 수량이 양수인 사례와 0개 사례를 각각 재현한다.
3. 공식 롯데마트GO/도와센터에 표시된 점포·상품·수량과 직접 일치하는지를 다수 지역·점포에서 비교한다.
4. 이마트 공식 앱의 점포 재고 연동 권한과 인증 처리 방식을 확인한다. 일반 웹 HTML이나 제타 배송 재고를 대체 수단으로 사용하지 않는다.
5. 원본 이용 허가 및 정확성 입증이 끝난 판매처만 통합 UI에 연결하고, 위치·상품·시간·상태를 표시한다. 실패/불일치는 '미확인'으로 남긴다.

## 정확도 보장 원칙

**HTTP 200이나 검색 결과 0건은 상품 재고 0개가 아니다.** 오직 점포코드·GTIN·판매 단위·명확한 수량을 일치시켜 실제 응답이 확인되었을 때만 '재고 있음' 또는 '0개'를 표시한다. 출처 접근이 불가능하면 기존의 공식 재고 조회 링크를 남긴다.
