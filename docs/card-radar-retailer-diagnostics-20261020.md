# 카드레이더 — 판매처별 재고 응답 진단 (2026-10-20)

## 목적
실제 재고가 확인되지 않은 이유를 표시한다. 특히 **수량 0 응답**, **상품 이름/코드 불일치**, **재고 API 미지원**, **HTTP 429**, **서버 5xx**, **중단된 잔여 검색**을 구분한다. 지도상 매장 위치를 재고 근거로 간주하지 않는다.

## 사용자 화면
카드레이더의 기존 `재고 확인 범위 > 자세히`에서 판매처별 응답 상태를 확인할 수 있다. 각 매장의 실제 수량과 상품명은 원래 목록에서 확인하며, 이 통계는 **응답 건수와 응답 행 수**이지 실제 판매처 전체 매장 수, 공식 재고 정확도, POS 실시간 동기화 여부가 아니다.

- **양수 재고 응답**: 선택된 카드팩과의 기본 일치 검증을 통과한 공개 집계 서비스 응답의 양수 수량 행. 공식 재고 확인이 아니다.
- **수량 0 응답**: 개별 조회된 상품에 대한 수량 0행. 다른 카드팩이 품절이라는 의미가 아니다.
- **상품 일치 응답 없음**: 전송과 응답에는 성공했지만 정확한 상품·위치·수량을 충족하는 행이 없었다. 품절 증거가 아니다.
- **상품코드 검증 실패**: GS25 상품코드 미확인 또는 이마트24 후보와 확정 정보의 충돌을 뜻한다. 0개로 취급하면 안 된다.
- **재고 데이터 미제공 / 호출 제한 / 서버 오류 / 자동 생략**: 조회 실패 또는 재고 미확인을 뜻한다. 실제로 요청하지 않은 자동 생략 작업은 실패 HTTP 요청 건수로 계산하지 않는다.
- **응답 수신 시각**은 모바일 앱이 공개 API로부터 응답을 받은 시각이며, 원본 POS 갱신시각이 아니다. 공개 중계 서비스는 데이터 시차가 있을 수 있다.

## 운영 및 데이터
각 조회의 오류 분류는 이미 브라우저에 일어난 결과로만 집계하며 사용자의 정확한 좌표, API 토큰, 응답 본문을 영구 저장하거나 제3자에게 보고하지 않는다. 공급원 API가 응답하지 않은 매장은 **품절 또는 0개로 변환하지 않는다**.

**남은 선행 조건:** 공식 판매처의 사용 허가가 확인된 재고 피드, 원본 갱신 시각, 실제 SKU/매장 코드별 서류 근거, 공식 앱과 15분 이내 비교한 수량 일치율.
