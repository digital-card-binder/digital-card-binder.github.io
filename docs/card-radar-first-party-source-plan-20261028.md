## 독립 아키텍처 제안

```text
포켓몬코리아/공식 판매 상품 카탈로그 -> 우리 제품 DB
                                                |
공식 매장/공공 위치정보 -> 우리 매장 DB             |
                     |                          |
                     v                          v
              [브랜드별 독립 공식 출처 어댑터]  <- PLU/GTIN/상품코드 매핑
                     |
            허용된 요청 수 + 서버 단기 캐시
                     |
          엄격한 점포코드·SKU·판매단위 검증
                     |
             재고 관측 기록(시각·원본·상태)
                     |
               카드 레이더 지도/목록
```

- 판매단위: **낱팩 / 박스 / 스타터덱 / 기타 세트** 반드시 별도 SKU 취급. 낱팩 30개의 재고를 박스 1개로 추산 금지.
- 상태: `positive(quantity>0)`, `confirmed_zero(quantity===0)`, `unavailable`, `unknown_sku`, `stale`, `unauthorized` 구분.
- 원본·매장코드·상품코드·확인시각이 입증된 항목만 최신 수량. 최신성 기준은 15분 이내를 목표로 판매처별 차등 적용.
- 요청 스케줄: 사용자 요청한 지역 및 제품만 확인. 동일 요청 중복 제거, 판매처별 동시 처리 제한, 오류 회로차단, 결과 짧은 캐시.
- 데이터 사용 허가 없는 판매처는 위치·공식 조회 링크까지만 제공한다. 조회 실패·미확인은 절대 품절 0으로 표시하지 않는다.
- 무료 인프라 우선: 기존 Vercel/Firebase 자원 재사용. 비용, 공급자 정책 및 서버 실행환경을 먼저 검증.

## 정확도 검증 기준 (매장 1곳 성공만으로 전국 운영 주장 금지)

1. 하나의 공식 상품명/GTIN과 판매처의 SKU가 **동일 제품 및 판매단위**임을 확인.
2. 공식 점포명/점포코드와 우리 지도의 좌표/주소가 같은 매장인지 검증.
3. 판매처 공식 앱/웹과 우리 서버를 같은 시각(가능하면 2분 내)에 비교하여 **양수 1건과 명시적 0건**을 모두 재현.
4. 서울·수도권·지방에서 각 판매처별 여러 점포를 확인하고, 상품명이 바뀌거나 동명이품인 실패 케이스도 테스트.
5. HTTP 200이어도 잘못된 상품·데이터 형식·점포 범위면 `unknown`; 401/403/429/5xx/timeout도 `unknown` 또는 `unavailable`.
6. 실패율·정확 일치율·SKU 매핑률·유효 재고 비율을 별도 지표로 측정.
7. 사용 조건 충족 및 실재고 결과 검증 후에만 `main` 및 실사용 사이트에 연결.

## 실행 우선순위

1. **이마트24 공식 직접 조회 POC**: 공식 PLU 상품 목록→지역 점포코드→수량, 응답 구조의 문자열 숫자 파싱, 실제 앱과 비교.
2. **CU 공식 직접 조회 POC**: 공식 매장 + 포켓CU 상품 검색/재고 결합. 조건 충족 여부 검증.
3. **세븐일레븐 공식 경로 조사**: 별도 승인 가능한 API와 SKU 매핑 검증.
4. **롯데마트/토이저러스 및 이마트 공식 조회**: 접근성과 사용 조건 해결 전에는 운영 실재고 자동조회 불가. 모바일 웹과 앱 정상 조회를 직접 대조.
5. **GS25**: 인증 의존성 때문에 공식 협의/승인된 접근 방법 우선. 개인 로그인 세션 공유 방식 금지.
6. 기타 마트는 공식 오프라인 수량 공급원이 확인될 때만 재고 수량 기능 활성화.

## 2026-10-28 이마트24 원본 v3 조회 POC 검증 (추가)

- **중요 수정:** 앞선 연구의 `/api/stock/v2/stock-search/store`는 HTTP 200이면서 재고가 문자열/숫자 형태로 직렬화되어 유효한 수량 응답이 아니었다. 공식 웹 페이지에서 현재 사용하는 **`/api/stock/v3/stock-search/store`**를 직접 조회한 결과 정상적인 재고 수량 배열을 확인했다.
- 공식 상품 검색 `POST https://everse.emart24.co.kr/stock/stock/search`: 키워드 `조로아&조로아크`에 상품코드 `8800286279914`, 상품명 `포켓몬)포켓몬카드(메가스타터세트 조로아&조로아크ex)` 한 건 반환.
- 공식 점포 목록 `GET https://emart24.co.kr/api1/store?page=1&search=양양물치항`: 점포코드 `27927`, 점포명 `양양물치항점`, 위도/경도 확인.
- 공식 v3 재고 `GET https://everse.emart24.co.kr/api/stock/v3/stock-search/store?searchPluCode=8800286279914&bizNoArr=27927`: `storeGoodsInfo.pluCd` 일치, `storeGoodsQty[]`에 해당 `BIZNO=27927`의 `BIZQTY=1` 반환.
- 실측 기록: [GitHub Actions 40639632654](https://github.com/digital-card-binder/digital-card-binder.github.io/actions/runs/40639632654), [GitHub Actions 40639724370](https://github.com/digital-card-binder/digital-card-binder.github.io/actions/runs/40639724370).
- 별도 모듈 `radar-service/lib/emart24-original.mjs`에 정확한 PLU/점포코드/패키지/수량 검증, 짧은 캐시와 제한된 매장 조회 구현. `radar-service/api/v1/emart24-original.js`는 사용 조건 및 운영 승인 전 **기본 503 비활성화**. 
- 관측된 1개는 특정 시각 단일 점포의 응답이며 공식 POS 실물 재고와 구매 가능성까지 보장하지 않는다. 독립 코드 구현이 제3자 재게시 허가를 대체하지 않으며, 운영 라우트 활성화는 명시적인 데이터 이용 승인과 비교 검증 이후에만 허용한다.
