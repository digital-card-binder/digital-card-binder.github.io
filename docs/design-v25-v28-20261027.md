## 디자인 원칙
- 어둡고 무거운 남색 도감이 아니라 화이트 + 페일 블루·라벤더·코랄 톤.
- 중요한 데이터와 카드 이미지·등급의 원래 색상은 변경하지 않음.
- 보유/미보유 시각적 의미와 색상 구분은 기존대로 보존; 상태 저장 로직 변경하지 않음.
- 밝아진 배경 위에는 진한 회청색 글자를 사용해 대비를 유지하고, 지나치게 큰 버튼과 과도한 장식은 배제.

## 배포/QA
- 각 차수는 별도 Git 커밋과 GitHub Verify를 거침. 전체 `npm test`는 Firebase 에뮬레이터 접근 규칙 테스트와 카드 DB 검사 포함.
- 배포 시 `npm run site:prepare`로 CSS 변경 해시를 모든 HTML에 동기화한 뒤 전체 테스트·데이터 보호 검사 진행.
- `data/`와 테마 감사/체크포인트, 기존 수집 소유권, Firestore 규칙, Card Radar 백엔드, Android APK 모두 변경하지 않음.
- Android WebView / Galaxy 렌더링과 명암비 실측은 자동 CI만으로 확인하지 못하므로 실제 모바일 시각 확인은 별도 필요.
