# M6 스톰에메랄다 데이터 메모

- 시리즈: MEGA / M6 / 스톰에메랄다
- 한국판 발매: 2026-08-21
- 수록 번호: 001/076–113/076 (총 113장)
- 한국 공식 이미지 CDN의 일반 카드 이미지는 우선 사용한다.
- 2026-08-25 기준 일부 2장 1조 스타디움 오른쪽 카드 및 077/076 이후 시크릿 레어는 동일한 한국 공식 이미지 URL 규칙에서 아직 응답되지 않을 수 있다. 해당 URL은 유지해 공식 이미지가 게시되는 즉시 별도 데이터 수정 없이 표시되도록 한다.
- M5는 118장 전체 번호, 표시명, 이미지, 중복 여부를 재검증했으며 구조적 누락이 없음을 확인했다. `name`이 비어 있고 `pokemonName`만 있던 포켓몬은 화면 표시명을 보완하고 ex/메가 표기를 교정한다.
