# 디지털 카드 바인더 — 29~32차 품질 안정화 (2026-10-28)

기준: `main` 13711183bf2380c4149fe4b9fc9ac3704029fb34

## 29차: PC·모바일 시각 QA
- 기존 브라우저 자동 검사 도구를 최신화: GitHub Actions에서 실제 체크아웃한 코드를 localhost에 서빙, Chromium 스크린샷 촬영 및 수평 넘침 계측.
- 1365px PC, 390px 모바일, 320px 소형 모바일에서 홈·검색·나만의도감·시리즈·팩·테마 및 주요 컬렉션 총 32개 렌더링 점검.
- 홈 검색 130px 가로 확장, 카드 제목 줄바꿈, 작은 화면 개인도감 사진 선택창 폭 수정.
- 개인 사용자 로그인 상태의 시각 QA는 테스트 계정 비제공으로 제외. 브라우저 검사 로그 및 스크린샷은 GitHub Workflow artifact에 저장.
- 테스트: `tests/stabilization-29-layout.test.mjs`.

## 30차: 누적 CSS 충돌 제거
- 구형 모바일 홈 검색의 `width:calc(100% + 130px)` 직접 제거, 29차의 안전한 100% 너비 적용 유지.
- 계정 메뉴가 이전 진남색과 새 밝은 배경이 섞이던 스타일을 실제 원래 규칙에서 밝게 변경.
- 기존 공통 터치 영역과 초점 링 CSS를 `--dcb-ux-touch`, `--dcb-ux-accent`에 연결; 중복 토큰 값을 하나로 통합.
- 해당 기존 테스트가 절대 색상 대신 새로운 디자인 토큰을 검증하도록 갱신.
- 테스트: `tests/stabilization-30-css-tokens.test.mjs`.

## 31차: 2만 장 이상 성능
- 나만의도감 검색 후보의 반복 쿼리 결과 캐시: 같은 쿼리로 선택/목록 확장/재렌더링 시 전체 카드 DB 재검색 방지.
- 검색 카탈로그가 다시 로드되면 캐시 무효화; query 변경이나 다른 도감의 보유/미보유 상태는 계속 정상 갱신.
- 통합 검색의 ERA_ORDER 순위를 미리 계산하고 시리즈·세트·보유 필터를 한 번의 순회로 처리.
- 카드 검색/선택기 이미지 비동기 디코딩 및 기존 60/50장 페이지네이션 유지.
- 21,000장 가상 테스트의 캐시 재사용/필터 정렬 정합성 검사.
- 테스트: `tests/stabilization-31-performance.test.mjs`.

## 32차: 로그인·보유·사진 업로드 회귀
- Google 로그인 전·후 UI 제어 검사.
- Firestore 저장 거절 시 사진 큐 및 원본 도감은 유지하고 업로드된 미연결 사진 문서만 삭제하는 롤백 검사.
- 성공 시 기존 카드 유지 및 새 사진 등록 검사.
- 보유 저장 완료 전까지 로컬 상태를 변경하지 않는지 검사; 공개 읽기 전용에서 쓰기 금지 확인.
- 전체 `npm test`에서 실제 Firebase 에뮬레이터 권한 규칙 테스트와 카드 이미지·테마 기록·시리즈 데이터 무결성 테스트 실행.
- 최종 캐시 무효화 `site:prepare` 및 보호 파일 변경 감시 후에만 병합.
- 테스트: `tests/stabilization-32-integration.test.mjs`.

## 안전 및 한계
- 보호 대상: `data/`, `db/`, `firestore.rules`, `android-app/`, Android APK, 테마 감사/검수 기록, Card Radar 백엔드.
- 변경은 웹 UI/CSS/JS 및 자동 검증/문서에 한정하고 회원 계정의 개인 도감 기록을 수동 초기화하거나 변환하지 않음.
