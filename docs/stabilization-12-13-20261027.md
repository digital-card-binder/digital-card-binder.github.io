# 디지털 카드 바인더 12~13차 — 앱 QA와 운영 관리 (2026-10-27)

## 12차: Android / PWA / 웹 최종 호환성 점검

현재 설치 앱은 **Android v1.0.2** (`versionCode 17`, 패키지 `io.github.digitalcardbinder.app.test`)이며, 기존 앱의 WebView가 `https://digital-card-binder.github.io/` 웹 화면을 읽습니다. 웹 도감/검색/나만의도감/스튜디오의 최신 변경은 별도 APK 버전 변경 없이 반영됩니다.

- Android 빌드 파일, 기존 설치 APK, 원격 `app-version.json`, PWA 매니페스트, 아이콘 경로를 교차 검사합니다.
- 기존 APK 서명 검사는 Android SDK `apksigner`로 검증하고, 패키지 ID·버전 코드를 `aapt`에서 검사합니다. **이 검사는 디바이스 설치·실행이나 FCM 푸시 전달을 증명하지 않습니다.**
- WebView는 신뢰 도메인 기반 Google 로그인 브리지, 이미지/카메라 업로드, 사용자 동의 기반 위치 요청, A4 인쇄와 뒤로 가기 기능의 기존 코드를 유지합니다.
- Android APK 바이너리/네이티브 코드를 변경하지 않으며, 사용자 설치 앱의 서명키·데이터 저장소도 변경하지 않습니다. 자동으로 앱을 삭제·재설치·초기화하지 않습니다.
- 실제 갤럭시에서 확인할 순서: 앱 실행 → Google 로그인 → 모바일 하단 이동(홈/검색/도감/내 도감/메뉴) → 검색 결과 60장 더보기 → 나만의도감 보유 표시 → 사진 업로드 → 바인더 스튜디오 A4/PDF 출력 → 카드레이더 내 위치 요청 → 앱 종료 후 재실행 및 보유 상태 유지.
- 모바일 브라우저/PWA에서도 위 웹 기능을 별도로 확인합니다.
- **실기기에서 카메라, 위치, 알림, 출력 권한은 직접 허용/거부 테스트가 필요하며 CI로 완전히 대체할 수 없습니다.**

## 13차: 사용자 의견 관리와 오류 확인

운영센터: `https://digital-card-binder.github.io/operations.html`

- 관리자 로그인 후 기존 `siteFeedback` 컬렉션의 전체 의견·새 의견·오류 제보·완료 건수를 서버에서 읽어 보여줍니다. 이 화면에는 작성자 이름/이메일/메시지 내용은 출력하지 않습니다.
- `받은 의견 관리`를 누르면 기존 대시보드의 관리자 의견함(`index.html#feedback-admin`)을 엽니다. 상태 변경은 기존 관리자 권한·버튼·Firestore 규칙을 그대로 사용합니다.
- `의견 현황 새로고침`은 수동 갱신으로, 새 의견이 없거나 조회 실패한 경우를 구분합니다.
- 오류 진단은 브라우저 탭 `sessionStorage`에 **최대 20건**, `script` 또는 `promise` 유형, 안전한 `*.html` 화면 이름, 시간만 보관합니다. **오류 메시지, 검색어, 이메일, 스택 추적, 전체 URL, 카드 보유 정보는 수집하거나 서버로 전송하지 않습니다.**
- 운영센터는 같은 탭에 저장된 오류 발생 화면과 개수를 보여주며 '오류 기록 지우기'로 지울 수 있습니다. 다른 탭이나 다른 기기의 오류는 보이지 않습니다.
- 사용자 의견의 자동 상태 변경·무단 삭제·자동 모니터링 외부 전송 기능은 만들지 않았습니다.
