커스텀 바인더 만들기

칸을 누르고 카드나 사진을 넣어 실제 바인더처럼 바로 편집하세요.

페이지형 바인더 저장 각 페이지의 그리드·슬롯·카드 배치를 독립 저장합니다. 기존 도감 문서와 보유 상태에는 어떤 값도 기록하지 않습니다.
간편 편집 바인더에서 원하는 칸을 눌러 선택하세요.
1
바인더 페이지 필수페이지를 추가하고 순서를 바꾸며 실제 바인더처럼 구성하세요.
1 / 1
2
바인더 그리드 필수현재 페이지의 카드 포켓 배열을 선택하세요.
스캔형 가져오기 사진으로 바인더 가져오기 사진 선택 → 페이지 영역·포켓 배열 확인 → 스캔 적용. 사진과 같은 배열로 나눕니다.
3 × 4

사진을 선택한 뒤 네 모서리와 사진 속 포켓 배열을 확인하세요. 스캔 적용 시 같은 배열로 슬롯을 만듭니다.

확실한 카드만 자동으로 우리 도감 카드로 교체하고, 애매한 슬롯은 후보를 보여줍니다.

촬영 팁 약간 비스듬해도 괜찮습니다. 네 모서리가 모두 보이고 페이지가 화면 대부분을 차지하게 찍으면 자동 보정이 가장 정확합니다.

3
배경 일러스트 선택원하면 페이지 전체에 배경 이미지를 넣을 수 있습니다.
4
확장 이미지 배치 선택원할 때만 확장 이미지를 여러 슬롯에 나눠 넣습니다.

이미지를 고른 뒤 미리보기의 원하는 슬롯을 눌러 선택하세요.

5
카드 추가 선택필요한 슬롯만 우리 도감의 실제 카드 데이터로 교체합니다.
검색어를 입력하면 전체 시리즈 도감에서 찾습니다.
6
선택 카드 편집 선택필요한 카드만 위치·순서·회전을 조정하세요.

이미지를 올리면 선택한 그리드와 비율을 확인합니다.

카드 크기 고정 미리보기와 향후 출력 모두 63 × 88 mm 기준을 유지합니다. 그리드가 커지면 카드가 줄어드는 대신 작업 영역이 넓어집니다.

7
나만의도감에 저장 필수완성한 바인더를 내 계정에 저장합니다.

로그인 후 나만의 도감과 연결할 수 있습니다.

로그인 상태를 확인하고 있습니다.

공개 여부는 프로필 설정에서 바인더별로 관리합니다.

8
전체 바인더 출력 선택필요할 때만 PDF 또는 실제 크기로 출력합니다.

중요 실제 카드/슬리브 출력은 인쇄 대화상자에서 배율을 100% · 실제 크기로 설정하세요. 모든 모드에서 칸 구분선·재단선이 PDF에 표시됩니다.
